# 白色家电企业财务报表研究

美的集团（000333.SZ）、海尔智家（600690.SH）、格力电器（000651.SZ）的财务与市场资料。研究期间为 **2023—2025 年度及 2026 年半年度**，市场观测保留2023—2026已有数据。分析主线为商业模式、会计处理、报表列示和经济含义。

数据分三类：接口直接采集的基础表、PDF 提取表、`build_*.py` 生成的计算表。已修正公式和重复字段，删除已知异常且无法确认的记录；电商样本保留并补充追溯字段。

## 校验与更新

依赖由 `pyproject.toml` 和 `uv.lock` 管理；首次使用执行 `uv sync`。PDF 提取还需 Poppler 的 `pdftotext`。电商重新采集另需登录态和 `uv sync --extra ecommerce`。

```sh
# 默认只读核验，不改 CSV，不访问外网
uv run python scripts/verify_all.py
uv run python scripts/verify_against_pdf.py

# 代码检查
ruff check scripts
ruff format --check scripts

# 原文核验结果需要更新时，显式生成证据表
uv run python scripts/verify_against_pdf.py --write

# 裁剪到研究期；默认不加--apply只检查，不访问外网
uv run python scripts/research_scope.py --apply

# 数据更新并审阅差异后，重新登记快照；不要用它掩盖意外修改
uv run python scripts/verify_inventory.py --write
```

主校验包含全库结构、快照完整性、研究期报表勾稽、关键公式独立复算和原有附注交叉检查。缺失、错列和未登记差异返回非零；特定历史口径差异与样本限制单独列出，不计为通过。

从原件重建使用 `extract_*.py --all`，计算使用对应 `build_*.py`。先重建输入，再生成对比表。研究期原始PDF均在 `年度报告/`；已移除早期年报自动下载和旧快照清理入口。`fetch_*.py` 多数访问外网并替换采集快照，不属于日常只读检查。

## 核对结果与限制

- 全库114张CSV、37,972行按2023—2026报告期/观测日期裁剪并登记快照；主校验1,779项通过、12项披露差异/样本限制、0失败，同时阻止范围外记录重新入库。
- 十二份本地PDF仅核对2023—2026核心科目；2023年报内的更早期初/比较数保留在原件中，2023平均周转率等直接读取该原件计算，不以期末数替代期初数。
- 修正涉及PB/净负债率分母、年末交易日、研发与海外占比口径、供应链关联方金额、行情重复列和京东组内去重；早期异常记录随范围裁剪一并移除。
- 来源等级不等于验证状态。半年报可能未经审计；公司转引的行业数字仍须保留第三方口径。
- B级数据库包含不同披露版本，季度累计数与年度重述数不能直接拼接。美的/格力2023Q4、海尔2023Q4/2024Q4已删除混版本相减值，保留年报直接披露的收入和归母净利润；收现质量已移除增值税还原估算列。
- 项目条件更新：奥维云网/GfK 分品牌、渠道、匹数的付费明细不可得，不以取得这些数据为研究前提。公开汇总仅作辅助；竞争格局需交叉来源，价格样本保留日期、完整型号、规格、渠道及优惠条件。无销量权重不称市场 ASP。
- 电商保留旧样本，2026-10-22 补采热泵干衣机 60 条，其中 51 个为此前未出现的 SKU；京东明细现有 1,670 条观测、1,501 个唯一 SKU。已补充商品链接和标题规格，按采集日分组；展示量不能推算品牌份额、真实销量或市场 ASP。
- 国庆数据删除预测、公司营销及无统计方法的记录，保留八条政府统计转引和一条历史行业基数，来源缩至三个。
- 2023年以前的独立财务、行情、行业及报告索引记录已删除。原始报告中的比较列和历史背景不裁改，不代表将其纳入研究期。
- DOCX/XLSX 是历史材料，原件未改。`财务比较.xlsx` 美的 2026H1 的 2610.52 亿元是营业总收入；比较营业收入应取 2600.4249 亿元。研发资本化、FIFO 成本传导等说明按新版来源规则使用。
