# 财务数据

研究范围：2017—2025 年度、2026 半年度。来源、期间、单位和披露版本必须一起使用；文件名或来源等级不代表整张表已经核实。

核验结果见 [项目入口](../README.md)，逐文件规模见 [数据清单](../数据清单.json)，原始金额、单位和 PDF 页码见 [原文交叉核验.csv](原文交叉核验.csv)。

## 使用限制

- 金额按列名使用：基础报表多为元，附注明细多为亿元。主要财务指标中的“营业成本”实为营业总成本，不能直接计算毛利率。
- 营业总收入与营业收入的差额包含金融业务利息、手续费等；其他业务收入本已包含在营业收入中。
- 已从三张报表及主要指标删除格力 20020930/20060331、海尔 20060630/20060930、美的 20110630，共 624 行；保留值未改。海尔 2018 年未确认的五条产品构成也已删除。其余 2017—2022 数据尚未逐项完成 A 级核验。
- 美的/格力 2023Q4、海尔 2023Q4/2024Q4 删除混版本累计相减的成本、总收入和复算列，保留年报分季披露收入、归母净利润；成本和毛利率留空。其余单季推算也须核对披露版本。
- `收现质量.csv` 已移除加权增值税率及含税还原估算；格力 2021 前五客户关联方占比和反推金额因披露冲突留空，匿名客户保留序号。
- 研发费用与含资本化的研发投入、归母净利润与含少数股东的净利润分别使用。美的未披露研发资本化金额时不能填零。
- 估值使用采集时点市值，财务分母为注明期间；股息率使用完整年度最后交易日的不复权价，2026 年不填“年末价”。
- `原材料价格指数.csv` 的 2026 年数据为截至采集日的年内均价，不能称全年均价。

## 复现

CSV 只通过脚本生成。先运行对应 `extract_*.py --all` 或采集脚本，再运行依赖它的 `build_*.py`，最后生成对比表。2019—2022 原文需要额外预置 PDF；采集脚本会访问外网。

```sh
uv run python scripts/verify_all.py
uv run python scripts/verify_against_pdf.py
```
