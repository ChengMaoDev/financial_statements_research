# 财务数据

研究范围：2023—2025年度、2026半年度。来源、期间、单位和披露版本必须一起使用；文件名或来源等级不代表整张表已经核实。

核验结果见 [项目入口](../README.md)，逐文件规模见 [数据清单](../数据清单.json)，原始金额、单位和 PDF 页码见 [原文交叉核验.csv](原文交叉核验.csv)。

## 投资决策与专项任务用途

- 投资选择以盈利质量、现金创造、资本占用、资产负债风险、股东回报和估值共同决定。`三家对比_*.csv`只提供入口，不能单凭某个比率排序选股。
- “最赚钱产品”优先读取`分部报告.csv`中的分部利润；三家公司分部口径不一致或未披露产品利润时，使用`主营构成.csv`中同一报告期、按产品分类的`主营利润=主营收入−主营成本`作为毛利额代理。计算时排除“其中”子项和合计重复，分别报告利润贡献额、贡献占比和毛利率。
- 产品结论只能落在披露粒度。产品大类、经营分部、地区分部和品牌/SKU不是同一层级；毛利额也不是扣除销售、管理、研发、财务费用及税项后的净利润。
- 三年预测从业务驱动开始：产品/地区收入、毛利率、费用率、营运资本、资本开支、净现金和分红。历史财务数据用于校准区间，不能把历史复合增速直接当作预测。
- 选定企业的股价区间应由预测利润、自由现金流、股本和净现金共同导出，并与历史/同业估值及分红回报交叉验证。财务预测和估值基准日不一致时不得直接拼接。

## 使用限制

- 金额按列名使用：基础报表多为元，附注明细多为亿元。主要财务指标中的“营业成本”实为营业总成本，不能直接计算毛利率。
- 营业总收入与营业收入的差额包含金融业务利息、手续费等；其他业务收入本已包含在营业收入中。
- 2023年前的独立记录全部删除；2023年报期初余额仍用于2023指标计算，来源为原件比较列，不能用期末余额代替。报告内的期初列、同期比较数与历史文字保留原样。
- 美的/格力 2023Q4、海尔 2023Q4/2024Q4 删除混版本累计相减的成本、总收入和复算列，保留年报分季披露收入、归母净利润；成本和毛利率留空。其余单季推算也须核对披露版本。
- `收现质量.csv` 已移除加权增值税率及含税还原估算；匿名客户保留序号，不仅凭金额相同推断身份。
- 研发费用与含资本化的研发投入、归母净利润与含少数股东的净利润分别使用。美的未披露研发资本化金额时不能填零。
- 估值使用采集时点市值，财务分母为注明期间；股息率使用完整年度最后交易日的不复权价，2026 年不填“年末价”。
- `主营构成.csv`的“主营利润”实为分产品毛利额；跨公司产品分类、成本分摊和披露粒度不同，先解决可比性再判断“最赚钱”。
- `原材料价格指数.csv` 的 2026 年数据为截至采集日的年内均价，不能称全年均价。

## 复现

CSV只通过脚本生成。先运行对应 `extract_*.py --all` 或采集脚本，再运行依赖它的 `build_*.py`，最后生成对比表。研究期PDF均在仓库内；采集脚本会访问外网，日期过滤与全库校验统一限定2023—2026。

```sh
uv run python scripts/verify_all.py
uv run python scripts/verify_against_pdf.py
```
