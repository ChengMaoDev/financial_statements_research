# 淘宝搜索页数据集（2026-10-21 快照）

采集时间：2026-10-21 15:55–16:10（北京时间）。
数据源：`s.taobao.com/search`，需登录态。
采集方式：Playwright 驱动已登录会话，**点击页面「销量」tab** 排序，每关键词 2 页。

原始/清洗文件：`taobao-{waterheater,dishwasher,dryer,integratedstove}.csv`，
共 355 条。解析逻辑见 `scripts/parse_taobao.py`。

## 四个必读口径陷阱

### 1. `sort=sale-desc` URL 参数无效，必须点「销量」tab

实测三种写法返回顺序几乎一致，且完全不降序：

| 写法 | 前 10 条付款人数 |
|---|---|
| `?sort=sale-desc` | 400+ / 37 / 0 / 88 / 4 / 0 / 400+ / 1 / 5 / 0 |
| 不带 sort | 400+ / 37 / 0 / 4 / 88 / 1 / 0 / 400+ / 5 / 0 |
| `?sort=bid` | 400+ / 37 / 4 / 0 / 400+ / 0 / 88 / 1 / 5 / 0 |

必须点击 `li.next-tabs-tab`（文本为「销量」）才真正触发排序。
点击后 URL **不变**，排序是前端行为。

### 2. 点击「销量」后，文案从「人付款」变成「人收货」

这是最容易踩的坑：只匹配「人付款」的正则在排序后返回 **0 条**。
采集器的正则必须同时接受 `人付款` 和 `人收货`。

本数据集全部为「人收货」口径（因为都点了销量 tab）。

### 3. 价格被打码，不能算均价

淘宝对部分商品隐藏价格尾数，只保留首位：

```
¥ | 1???   ← 真实价 1000–1999
¥ | 4??    ← 真实价 400–499
¥ | 2???   ← 真实价 2000–2999
```

四个品类的价格可读率：

| 品类 | 条数 | 价格可读 | 可读率 |
|---|---|---|---|
| 洗碗机 | 89 | 9 | 10% |
| 集成灶 | 89 | 27 | 30% |
| 干衣机 | 89 | 3 | 3% |
| 热水器 | 88 | 1 | 1% |

**因此本数据集不做均价、价格带、价格分布分析。**
`价格_raw` 仅作原始记录保留。

### 4. 店铺名会被「N年老店」抢占

卡片末尾常见 `9年老店`、`15年老店`、`16年老店`，它同样以「店」结尾，
若用「最后一个以店结尾的段」取店铺，会取到店龄标签。

已修正：排除 `^\d+年老店$`。修正前 7 条误判，修正后店铺字段为空
（宁可留空，不给错误店铺名）。

## 字段说明

| 字段 | 口径 |
|---|---|
| `关键词` | 热水器 / 洗碗机 / 干衣机 / 集成灶 |
| `页码` | 1 或 2 |
| `商品ID` | 从 `item.htm?id=` 提取 |
| `标题` | 卡片首段 |
| `销量展示` | 原文，如 `1万+人收货`、`400+人收货` |
| `销量_折算` | 折算数值，`1万+` → 10000。**仅供分档** |
| `价格_raw` | 原文，可能含 `?` |
| `价格可读` | 1 = 无打码；0 = 被打码 |
| `店铺` | 卡片末尾真实店铺名，店龄标签已排除 |

## 能回答什么

1. **品类内部的相对热度梯队**。按销量排序位，Top 10 是谁、品牌集中度如何。
2. **品牌的铺货与热度结构**。海尔官方旗舰店在热水器 Top 5 占 3 席（1万+、5000+、4000+）。
3. **跨平台对照**。与京东联盟、拼多多同品类对照，看品牌排序是否一致。

## 不能回答什么

- 销量绝对值、销售额、市场份额。「N人收货」是累计口径 + 区间取整，且带 `+`。
- 均价、价格带。价格被打码，可读率 1%–30%。
- 淘宝全平台品牌份额。只是销量排序前 88 条，且只覆盖 1–2 页。
- 与京东联盟「30 天引单量」换算。一个是累计收货人数，一个是 30 天引单量。

## 复现

```sh
# 1. Playwright 打开 s.taobao.com 并登录
# 2. 检索关键词 → 点击「销量」tab → 抓 2 页 → 点击「下一页」 → 抓第 2 页
# 3. 校验
uv run python3 scripts/parse_taobao.py --audit
```

采集节奏：页间 6–8 秒；每次滚动 3–4 次触发懒加载。

## 引用规范

引用时必须写明：

1. 平台是**淘宝/天猫**，不是全渠道；
2. 口径是**累计收货人数**（不是 30 天、不是档期）；
3. 数值是**区间下界**（带 `+`），只可做分档与排序；
4. 样本是**按销量排序的 2 页**，不是全量；
5. 价格不可用（打码）。
