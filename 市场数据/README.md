# 市场数据

保留行业资料、公司产销量、行情和电商采集快照。主要采集时点为 2026-10-21，热泵干衣机于 2026-10-22 补采；各表实际覆盖期间不同，使用前查看日期列。

## 文件入口

| 位置 | 内容与边界 |
|---|---|
| `国庆档期数据.csv` | 八条政府统计的媒体转引；预测、公司营销及无统计方法的记录已删除 |
| `行业基数_1-8月.csv` | 1 条获来源支持的行业基数；原来另三条引用不支持，已移除 |
| `来源.csv` | 三个网页来源、发布日期、机构与限制 |
| `公司产销量.csv` | 年报披露的生产、销售、库存；存在统计范围差异 |
| `行业数据_年报引用.csv` | 公司报告转引的第三方行业数据，不能直接视为审计确认值 |
| `结构化/` | 股东、估值、复权/不复权日线、两融、北向持股、原材料、汇率、房地产景气指数 |
| `电商/` | 京东联盟原始导出、组级面板、SKU 明细，及淘宝、拼多多快照 |
| `京东空调快照.csv`、`快照/` | 平台展示样本与探测原始响应，保留作追溯材料 |
| [股东户数唯一入口](../财务数据/股东户数.csv) | 本目录原重复副本已删除 |

## 引用边界

- 现有国庆表仅保留 S1/S5 的政府统计转引；S2 仅保留历史 1—8 月行业基数。预测值、海尔营销数字及 S4 无统计方法的卖场数字已删除，生成脚本也已同步。
- 品牌级、单品级、渠道级档期销量及加权 ASP 公开不可得；不能用展示销量、单款报价或样本中位数替代。
- 京东联盟明细保留检索词观测，组内 SKU 去重。30 天引单量存在量化和组级重复，不可求和；原始结果未排序，不能称最高引单样本。滚动窗口两期相减不等于期间销量。
- 淘宝展示值为累计人数，部分为区间下界，价格大量打码；拼多多混合“已拼/已抢/总售”，排序位不可用。两者均不代表档期销量或品牌份额。
- 北向持股表止于2024-08-16；海尔股东户数没有2023—2026样本，已移除范围外历史记录。房地产景气指数仅保留研究期已有观测，不能替代开工、竣工或销售面积。
- 期货主力连续价格是成本代理，包含换月等影响，不能等同企业实际采购价。2026 年均价是截至采集日的年内均价。

## 电商字段与采集

2026-10-21 登录态采集的原始导出保留。2026-10-22 补采“热泵干衣机”一页 60 条，新增 51 个此前未出现的 SKU；京东明细为 1,670 条观测、1,501 个唯一 SKU，面板 869 组，按采集日期分开。样本数见 [数据清单](../数据清单.json)。

三平台补充商品链接、标题中的匹数/容量/能效、二手或箱损标记、套装或配件标记。规格仅为标题原句，缺失留空，多值保留，不代表已核实实际选中规格。拼多多另保留展示主语、数值性质与价格口径；“总售/热卖”的统计粒度标为未确认。

| 平台 | 输入与处理 | 使用注意 |
|---|---|---|
| 京东联盟 | `jdunion-*.csv` → `build_jdunion_panel.py` | `o30/c30` 为 30 天引单/佣金展示；同采集日、同店铺共享值按组折叠，双零时按 SKU 分组。平台真实聚合层级未披露。组内唯一 SKU 中位价，来源关键词全部保留。品牌归一不等于上市公司合并口径 |
| 京东搜索 | `快照/raw-*.txt` → `clean_jd_snapshot.py` | “已售”累计展示可能混合评价含义，数值为区间；卡片价格可能含国补。两次下界相减不能得到真实期间增量 |
| 淘宝 | `taobao-*.csv`；`parse_taobao.py --audit` | 需实际点击“销量”tab；展示为“人收货”，带 `+` 为下界。`价格可读=1` 表示无打码；店铺可能缺失，页内存在并列 |
| 拼多多 | `scripts/_pdd_inbox/*.tsv` → `build_pdd_csv.py` | 页面通过 CDP 捕获搜索响应。保留 `sales_tip`，不用 API `sales`；“总售”等粒度未确认，`N人想拼` 不算销量。价格可能是起售价，广告列不宜过滤 |

检索结果仍可能含套装、耗材、布罩烘干机、空调扇、锅具及二手/箱损商品。跨品类或跨平台比较前应核对完整型号与规格，不能直接引用全品类中位价。京东 `<100` 的展示值也未独立证实全部为精确计数；零引单但有佣金的原因未经确认。

原始 `jdunion-fridge.csv` 因“冰箱”命中食品而不进入面板，保留用于追溯。各平台登录、风控和排序状态会变化，现有清洗可复现不代表可以从零重新采到同一批商品。

## 复现

```sh
# 已有原始导出的离线清洗
uv run python scripts/build_jdunion_panel.py
uv run python scripts/build_pdd_csv.py
uv run python scripts/parse_taobao.py --enrich --audit

# 全库只读检查
uv run python scripts/verify_all.py
```

`fetch_national_day.py` 会先检查来源原句，全部成功后才写表；`--source-dir` 可指定已核对的 S1.txt、S2.txt、S5.txt 离线文本。行情等 `fetch_*.py` 需要外网并会更新快照。原始采集文件不应为了目录整洁而删除。
