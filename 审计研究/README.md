## 中间材料

统一放在 `中间材料/`，保留内部分类方便追溯：

- `审计报告/`：官方独立报告、各市场研究摘页、检索与OCR记录、人工复核配置；`事务所评价来源/`包含评价证据及正文模板。
- `审计机构沿革_2006-2025/`：历年年报、变更公告、检索响应、下载元数据、扫描摘录与正文模板。两个正文模板中的相对链接供生成器转换，以最终报告为阅读入口。
- [任务说明](中间材料/任务说明/prompt_collect_audit_reports_2023-2026H1.md)：最初收集任务，保留原文及当时路径。
- [文件整理记录](中间材料/文件整理记录.json)：原路径、新路径及迁移前SHA-256。历史检索、OCR和下载JSON保留原文，其中的旧路径可按此映射定位。

## 数据与复现

CSV按项目约定留在 `财务数据/`，由脚本生成：

- [审计报告文件清单](../财务数据/审计报告文件清单.csv)
- [审计报告对应清单](../财务数据/审计报告对应清单.csv)
- [审计机构沿革](../财务数据/审计机构沿革_2006-2025.csv)

在仓库根目录运行以下命令，可离线重建三份报告及清单：

```powershell
python -X utf8 scripts/collect_audit_reports.py --build --verify
python -X utf8 scripts/build_audit_summary.py
python -X utf8 scripts/build_auditor_history.py
python -X utf8 scripts/reorganize_audit_files.py --verify
python -X utf8 scripts/verify_all.py
```

采集与生成代码保留在 `scripts/`。原有 `年度报告/`、`H股年报/`、`D股年报/`中的财报通过清单引用；整理前已保存的原件及检索证据内容保持原样。
