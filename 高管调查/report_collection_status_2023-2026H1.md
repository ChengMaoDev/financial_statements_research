## 方法与限制

1. 优先按港交所发行人及披露日期列表定位，核对完整报告类型；香港7份均选中文。德国渠道4份英文原件来自发行人官网／EQS，不是香港版报告的改名副本。
2. 通过封面、目录、正文经营与治理章节、股东／股本章节、财务报表及附注和文档末尾检查完整性；11份新文件另作封面渲染目视检查。每份已记录内容审查PDF页序。页序与报告印刷页码可能不同。
3. 原有境内文件优先以巨潮官方全文精确哈希核验。其他官网版本或香港合并公告可能压缩方式、分页不同，未覆盖原件，也未以合并附件的页数冒充原件页数。
4. PDF镜像使用原有convert_pdf/check_pdf函数，先输出系统临时预览目录并校验，再创建新目录镜像；原有转换脚本和原件未修改。
5. 日期按所选版本及披露渠道分别记录；德国EQS索引日期可能晚于中国境内披露日期。不会因日期不同就认定报告属于不同会计年度。
6. 该核验确认文件身份、结构、来源及转换一致性，不构成对财务数字、审计意见或研究结论的重新审计。

## 复现

在已具备Python及Poppler的仓库环境执行：

```powershell
python -X utf8 scripts/finalize_report_collection.py --download
python -X utf8 scripts/verify_conversion.py --only pdf
python -X utf8 scripts/collect_multimarket_reports.py verify-baseline
```

首条命令只下载计划中的固定官方URL；来源哈希改变或同名文件冲突时停止，不覆盖。新镜像在系统临时目录试转；旧镜像不重新写入。清理后的首次重新执行会建立新的执行前快照，并重建验证中间文件。
