## 文件说明

本次人物调查的过程资料统一保存在本目录：CSV为研究底表，JSON为来源配置，`scripts/`为配套脚本。原始PDF保存在仓库`origin/`，三份正式报告位于仓库根目录。

| 文件 | 用途与边界 |
| --- | --- |
| `people.csv` | 94条人物索引：美的28、海尔35、格力31；区分核心、普通高管、历史、治理背景及待查关系人物，不代表94人均有同等深度档案 |
| `career_timeline.csv` | 95条已选履历与任职事件；不把未知时间硬补为连续任期 |
| `relationships.csv` | 32条有来源的控制、持股、任职、亲属及历史平台关系；法律主体与自然人分开 |
| `sources.csv` | 42项实际使用或明确列为受限线索的来源，含13份财报、5份新归档补充PDF及24项其他来源；网页与学校/机构自述并非全部独立认证 |
| `evidence.csv` | 三份报告325处正文与来源的关联，带报告行号、主题、PDF页序/网页定位及限制；多条引用可能来自同一来源，不代表325份独立证据 |
| `ownership_context.csv` | 40条与人物、控制及名义持仓解释有关的四期观测，单位为股；不是全量24张前十表数据库 |
| `ownership_changes.csv` | 上述10组指标的三个区间、共30项快照差，保留两端来源与公式；差额本身不证明市场交易 |
| `research_sources.json` | 人工选定来源配置，关联既有财报来源清单及补充资料 |
| `scripts/research_personnel_sources.py` | 从原始PDF提取指定页或查找关键词 |
| `scripts/finalize_personnel_research.py` | 保存已审阅研究记录，生成底表并整理报告引用 |

CSV均使用UTF-8 BOM。人物ID以公司为边界；同名、别名与机构关系不凭相似名称自动合并。证据定位形如`M-P:359`，表示`sources.csv`中的M-P来源、PDF文件第359页；页区间保留。PDF页序和印刷页码不同，统一台账不推算印刷页码，回原件页脚查看。

## 复现与继续工作

在已有Python和Poppler的环境中：

```powershell
python -X utf8 personnel_research/scripts/research_personnel_sources.py pages 美的2025 69 71
python -X utf8 personnel_research/scripts/research_personnel_sources.py pages 格力_20200118问询回复 1 2 3
python -X utf8 personnel_research/scripts/finalize_personnel_research.py
```

第一个脚本只读取原件，在系统临时目录建立可丢弃的提取缓存，不覆盖原始PDF。第二个脚本依据已审阅的人工研究记录和来源配置生成CSV与引用索引；它不自动推断人物身份，也不证明事实。更新报告引文可使用`〔M25:69-71〕`这类标记后执行整理脚本；已生成链接也可保留。

修改报告后如需更新`evidence.csv`中的报告行号，应重新执行整理脚本。修改事实时同步维护人物、事件、关系记录及来源，不仅修改展示文字。不要覆盖他人已作的人工更正。
